# Code of Conduct

## Our standard

We want the Diagrams.so open-source projects to be welcoming and productive for everyone. Participating in these projects (issues, pull requests, discussions, and any project space) means treating others with respect, regardless of background, identity, or experience level.

Expected behavior:

- Be respectful and constructive. Critique code and ideas, never people.
- Assume good faith, and be patient with newcomers.
- Accept review feedback gracefully, and give it the same way.
- Keep discussions on topic and professional.

Unacceptable behavior:

- Harassment, insults, or discriminatory language of any kind.
- Personal attacks, trolling, or sustained disruption.
- Publishing others' private information without permission.
- Sexualized language or imagery, or unwelcome advances.
- Any conduct that would be unlawful or that a reasonable person would consider inappropriate in a professional setting.

## Enforcement

Report conduct issues to **success@diagrams.so**; reports are handled confidentially. Project maintainers may edit or remove comments, commits, issues, and other contributions that violate this code, and may temporarily or permanently ban contributors for behavior they judge inappropriate. Maintainers who do not follow this code in good faith may be removed from the project team.

## Scope

This code applies in all project spaces and when an individual is representing the project in public.

This document is adapted from the spirit of the Contributor Covenant (contributor-covenant.org).
